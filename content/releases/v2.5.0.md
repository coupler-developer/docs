  확인하며, 적용 뒤 문제는 새 runtime forward fix로 복구한다.
- API: 배포 직전 운영 source `e4e344f3287c3c81a260ed98d00d1e8ce5a69960`은 additive column과 기존 경로를
  계속 읽을 수 있다. 다만 새 NextPush가 설정 command를 사용한 뒤 API만 되돌리면 해당 동작이 실패하므로
  NextPush rollback이 동반되지 않는 장애는 `c0e70bbe` 기반 forward fix를 사용한다.
- Admin: live source `bf64bce4a22a62ed6e314c25bef623aa06caebf1`와 index SHA-256
  `acd7f9cfba099686aaf20d672811b9b16c50c3e325cd2010a36644ba40cf4c87`을 배포 시 backup metadata로 봉인하고,
  실패하면 그 exact backup의 asset·index를 복원한다.
