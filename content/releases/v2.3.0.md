## 롤백 기준

- DB: `RESUMED` 뒤 snapshot/PITR로 되돌리지 않는다. 현재 runtime과 데이터 보존을 전제로 forward fix 또는
  통제된 lossless reconciliation을 사용한다.
- API: 직전 운영 기준점으로 되돌리기 전에 현재 DB와 모든 지원 consumer-interface 호환을 재검증한다.
- Admin: 배포 직전 정적 산출물 백업을 복원하고 nginx 내부·외부 응답을 재확인한다.
- Mobile Store: iOS는 승인 전 제출 상태에서 중단할 수 있다. Android는 이미 출시됐으므로 새 Store build
  또는 NextPush rollback을 별도 판정한다.
- Mobile NextPush: Android·iOS Production을 각각 직전 label로 rollback하고 deployment history를 재확인한다.
- docs: terminal 병합 전에는 같은 PR만 수정한다. docs 태그나 Release를 선행 생성하지 않는다.
