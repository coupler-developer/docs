1. Draft PR과 필수 CI를 통과한 pending 기록으로 preflight를 수행한다.
2. clean mobile `main`의 exact commit에서 Android Release AAB를 생성하고 version, 서명, 운영 API origin, digest를 검증한다.
3. 제출 AAB와 source를 `submitted/android-2.5.1-106` marker로 고정한 뒤 Google Play에 제출한다.
4. 심사 승인과 공개 출시를 확인하고 Android 운영 smoke를 수행한다.
5. exact mobile source에 annotated tag `v2.5.1`을 고정하고 이 기록을 terminal 상태로 갱신한다.
6. docs 최종 Gate 통과 후 기록 PR을 병합하고 annotated tag `v2.5.4`를 생성한다.
